Três formas de incluir CSS

Este parágrafo recebe CSS de 3-estilo.css.

Este parágrafo recebe CSS da tag style.

Este parágrafo recebe CSS inline.

O CSS externo é carregado por <link rel="stylesheet" href="3-estilo.css"> no cabeçalho. Ele permite reutilizar as mesmas regras em várias páginas.

O CSS interno fica em um elemento <style> no cabeçalho do HTML.

O CSS inline fica no atributo style do próprio elemento.
