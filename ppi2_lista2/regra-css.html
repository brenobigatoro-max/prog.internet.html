O que é uma regra CSS?

Uma regra CSS associa um seletor a um bloco de declarações para definir a aparência dos elementos selecionados. Cada declaração reúne uma propriedade e um valor.

h1 {
  color: blue;
}

O seletor h1 seleciona os títulos de nível 1; a propriedade color define a cor do texto; o valor blue aplica a cor azul.
